# 香菜番茄钟

一个悬浮在 Mac 桌面上的工作计时小组件。单击开始、再单击结束，自动记下你每天工作了多久。

小组件的形状可以随便换：上传一张图片，它会自动抠出主体；或者写一句话，让 AI 生成一个图标。

## 能做什么

- **悬浮在桌面上**：浮在所有窗口上面，切换桌面空间也跟着你；拖到哪都行，形状外的透明部分可以点穿。
- **一键计时**：单击开始，再单击结束。小组件上一直显示「开始 / 正在计时」和「今天已工作多久」。
- **每次开始、结束都给你一句鼓励**：结束时还会告诉你这一段干了多久、今天一共多久。
- **工作统计**：右键 →「工作统计」，按周、月、年看总工时、日均和柱状图，可以往前翻。
- **上传图片换形状**：用 macOS 自带的「抠主体」能力（和照片 App 长按抠图是同一套），在本机完成，不上传图片。
- **写一句话生成图标**：优先用 Mac 自带的 Image Playground（需要开启 Apple Intelligence）；用不了时改用魔搭 ModelScope 的免费生图接口（需要你自己的访问令牌，见下文）。
- **一天按凌晨 5 点切换**：熬夜工作到两三点，也算在当天。
- 菜单栏有一个计时器图标，计时时显示时长；退出 App 不会中断计时，下次打开接着算。

## 安装

需要 macOS 14（Sonoma）或更新版本，Apple 芯片和 Intel 芯片都能用。

1. 到 [Releases](../../releases) 下载 `XiangcaiTimer-macOS.zip`，解压得到「香菜番茄钟.app」，拖进「应用程序」文件夹。
2. 第一次打开时，系统会提示「无法验证开发者」。这是因为这个 App 没有付费做苹果签名。打开方法：
   - 在「应用程序」里**右键**「香菜番茄钟」→ 打开 → 再点一次「打开」；或者
   - 打开「系统设置 → 隐私与安全性」，在下方找到这个 App，点「仍要打开」。
3. 想开机自动启动：系统设置 → 通用 → 登录项，点「+」选择「香菜番茄钟」。

## 怎么用

| 操作 | 效果 |
|---|---|
| 单击小组件 | 开始 / 结束计时 |
| 拖动小组件 | 挪位置（下次打开还在原地） |
| 右键小组件，或点菜单栏的计时器图标 | 打开菜单：统计、换形状、大小、退出等 |

### 用一句话生成图标

如果你的 Mac 已开启 Apple Intelligence，直接右键 →「换形状：写一句话生成…」就能用。

否则需要一个魔搭 ModelScope 的访问令牌（免费）：

1. 登录 [modelscope.cn](https://modelscope.cn)，进入「个人中心 → 访问令牌」，复制一个令牌。
2. 右键小组件 →「设置生图令牌（魔搭）…」，粘贴后保存。

令牌只保存在你自己的电脑上。生成时，你写的那句话会发送给魔搭来生成图片。

## 数据存在哪

全部保存在本机：`~/Library/Application Support/XiangcaiTimer/`

- `store.json`：每一段计时记录（开始、结束时间）、小组件位置和大小
- `shape.png`：当前的自定义形状
- `modelscope-token.txt`：魔搭令牌（如果设置了）

右键 →「打开计时记录文件夹」可以直接打开这个文件夹。

## 自己编译

需要 Xcode 或 Command Line Tools（`xcode-select --install`）。

```bash
./build.sh          # 编译并安装到 ~/Applications
./build.sh --zip    # 另外打一个发布用的 zip
```

所有代码都在 `main.swift` 一个文件里。想换成自己的鼓励语，改 `Cheer` 里的两组句子就行。
